# Concept B 參考圖排版轉譯設計

日期：2026-09-09

## 目標

保留 Concept B 現有內容、圖片與拼貼式首屏，將兩張醫療網站參考圖的排版語言轉譯到學會網站。整體維持大面積純白底，並以 `#0F8DB2` 作為主要互動色。

## 參考圖設計元素

- 大圓角媒體框與資訊卡，邊界柔和但層級清楚。
- 深色粗體無襯線標題，字距緊密、段落短而有力。
- 全大寫英文眉題、小型膠囊標籤及清楚的數字資訊帶。
- 圖片與文字卡採非對稱模組化編排，避免平均分割造成僵硬。
- 玻璃卡以半透明白色、背景模糊、亮邊與低透明陰影覆蓋於照片上。
- 大面積白色畫布之間穿插極淡冷藍灰資訊區，primary 僅用於 CTA、標籤與互動狀態。

## Concept B 應用方式

### Hero

維持現有六格拼貼及原始圖片。主要文字卡改為半透明玻璃面板，加入 `backdrop-filter`、細白邊與低透明藍色陰影。標題與 CTA 採參考圖的緊湊粗體層級，但不改寫內容。

### 快速入口

將三張等高內容卡調整為更接近參考圖的橫向資訊帶：每項保留編號、圖示、標題、短說明與連結，卡片降低高度並以細分隔與留白建立節奏。桌面三欄、手機單欄。

### 學術活動與專業資源

維持現有圖片與內容，改以一張大媒體模組搭配白色圓角資訊面板。資訊內部以膠囊眉題、粗體標題及清楚 CTA 排版，不新增虛構資料。

### 最新消息

維持三欄圖片卡；圖片使用大圓角上緣，內文縮短視覺高度，將分類呈現為小型膠囊標籤，日期與標題依參考圖建立緊密層級。

### 會員服務

沿用現有會員功能資料，桌面以主卡略放大、次要卡克制的層級呈現；手機回到單欄。互動狀態使用 `#0F8DB2`，不改變連結目的地。

## 色彩與材質

- Page background：`#FFFFFF`
- Primary：`#0F8DB2`
- Primary dark：`#086A84`
- Ink：沿用 Concept B 深青藍文字色
- Supporting surface：僅允許極淡冷藍灰，且不得取代大面積白底
- Glass：半透明白色、柔和 blur、白色細邊、藍綠低透明陰影

## 響應式與無障礙

- 保留現有語意標題、連結及圖片替代文字策略。
- 桌面維持非對稱拼貼；平板縮為兩欄；手機單欄並避免水平溢出。
- 玻璃卡在不支援 blur 或偏好降低透明度時，需退化為高不透明白色面板。
- 焦點樣式、文字與按鈕維持可辨識對比；動畫在 `prefers-reduced-motion` 下停用。

## 驗收

- Concept B 的首屏拼貼內容與圖片完全保留，文字卡呈現玻璃材質。
- 全頁維持大面積白底與 `#0F8DB2` primary。
- 後續區塊具有參考圖的大圓角、粗體排版、淡色資訊帶與清楚的模組節奏。
- Desktop、tablet、mobile 無溢出或文字裁切。
- 現有 Angular tests 與 production build 通過。
