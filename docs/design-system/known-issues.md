## 字級階梯的合併候選

階梯目前有 48 階，仍比成熟系統該有的多——三案是各自繪製的。

### Icon 階梯收斂的實測結果

**已完成。** 11 階（38／36／30／28／26／25／24／21／20／19／18px）收斂為 Material
光學尺寸的 4 階（40／32／24／20），最大位移 4px：

| 原值 | 新值 | 位移 | 使用處 |
|---|---|---|---|
| 38px | `icon-xl` 40px | +2 | 快速入口卡片圖示 |
| 36px | `icon-xl` 40px | **+4** | 會員卡片主圖示 |
| 30px | `icon-lg` 32px | +2 | 列箭頭、資源卡片圖示 |
| 28px | `icon-lg` 32px | **+4** | B 案會員徽章 |
| 26px | `icon-md` 24px | −2 | 列標題圖示 |
| 25px | `icon-md` 24px | −1 | B 案資源面板圖示 |
| 24px | `icon-md` 24px | 0 | B 案資源連結圖示 |
| 21px | `icon-sm` 20px | −1 | B 案箭頭 |
| 20px | `icon-sm` 20px | 0 | B 案封存圖示 |
| 19px | `icon-sm` 20px | +1 | B 案按鈕內圖示 |
| 18px | `icon-sm` 20px | +2 | B 案活動細節圖示 |

四個寬度實測：差異主要是圖示字身變大（白底轉為強調色），非版面錯位。
頁高變動 A 案 +2～+6px、B 案 +24px（8017px 中，0.3%）、C 案 +6px，無文字重排。

低位移的替代階梯（38／30／24／20，最大位移 2px）也實測過：A 案頁高不變，
但 C 案在 1024px 反而縮 33px，並未比較好，故採用 Material 標準階梯。

### Title 的三組 `-alt`（風險中，會造成文字重排）

| 合併 | 差距 | 影響的選擇器 |
|---|---|---|
| `title-md-alt` → `title-md` | min 23→24px | `.news-item h3` |
| `title-sm-alt` → `title-sm` | max 30→29px | `.quick-row-heading h3` |
| `title-2xs-alt` → `title-2xs` | max 25→26px、vw 1.55→1.6 | B 案資源面板 `h3` |

**已實測過**：三項一起合併會使 A 案在 375px 寬時 `.news-item h3` 由 23px 變 24px
而換行，頁高由 7305px 增為 7377px（+72px），另在 1024／768／1440 產生約
1.2 萬～1.4 萬像素的差異。因此重構時已全數退回，維持零視覺變化。

要合併必須接受這個重排，或改為調整卡片寬度與字數上限。

### Headline 的 `headline-md` / `headline-sm`（已合併）

**已完成。** 兩階相差 2–4px，分別用於 B 案的活動與資源面板標題，合併為單一
`headline-md`。**往小的那一階合併**：活動標題帶 `text-wrap: nowrap`，放大有溢出風險，
縮小則無。資源面板標題因此縮 2–4px。

四個寬度實測：僅 B 案受影響，頁高在 1024／768／375 各減 2px，1440 無變化，
差異 0.32%，無溢出也無重排。

## 仍為字面值的樣式

| 項目 | 位置 | 原因 |
|---|---|---|
| 6 筆間距（34、38、42 ×3、54） | `concept-page.scss` | 距離間距階梯超過 1px，強行吸附會改變版面 |
| 頁尾深色系（`#24272a`、`#202225`、`#22272a`、`#586067`） | `site-footer.scss` | 深色帶尚未納入 token；需要一組 inverse surface token |
| 比較頁配色（`#f5f7f8`、`#5a696d`） | `comparison.scss` | 該頁不在任何主題容器內 |
| 展示頁 chrome 配色（`#16191c`、`#e2e7e9` 等） | `design-system-page.scss` | 刻意的：展示頁的外框不該套用被展示的主題，否則無法中立呈現三案 |
| 漸層節點（`#d5eaf0`、`#9ed4e0`、`#7f9aa9`、`#315b70`、`#c9e5e2`、`#a9d5d2`） | `concept-page.scss` | 單點使用，色相與主色階不同，收斂會改變視覺 |
| `.skip-link` 的 `#fff` / `#111` | `_utilities.scss` | 必須在任何主題上都維持可讀 |
| 佔位漸層的第二個白 | `concept-page.scss` | 需要與 surface token 不同的第二個白 |

## 若最終只留一案

落選兩案的 token 與覆寫會成為死碼。建議將落選案的樣式與素材移入
`docs/archive/`，並從 `_tokens.scss` 移除其主題區塊——這是 token 層完整定義
三個主題最直接的好處：刪除一個主題只需刪掉一個區塊。
